Fractal Explorer

Interactive desktop explorer for finite-stage self-affine constructions in complex dimensions. It accepts an arbitrary complex matrix and an alphabet of complex vectors then generates the fractal. You can look around at the fractal from different directions or different dimensions.

If you already have python on a Windows computer, just download, unzip, and run the .bat. For Mac, you can run the bash in the readme.

FUP Interactive Explorer

An interactive Python application for numerically investigating FUP exponents associated with finite-stage, higher-dimensional Cantor digit sets. It computes operator norms of restricted discrete Fourier transforms, compares the resulting finite-stage exponents with the Hilbert–Schmidt norm, and plots results for isotropic and anisotropic diagonal dilations.

Cantor-Fractals

A javascript website for constructing self-affine rectangle fractals in the browser. This is an earlier version of the above Fractal Explorer with a more intuitive ui. It can make gifs of stages developing in 2D and 3D. To use just download and open index.html.
